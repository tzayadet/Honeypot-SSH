SSH Honeypot Lab

A controlled-environment prototype that records SSH authentication metadata and requested commands for security learning and defensive analysis. This page is a project overview, not a live honeypot or telemetry feed.

View source on GitHubRead documentation
01 / OBSERVABILITY

Authentication events

Records source address and submitted username. Password values are never stored or printed.

02 / SAFE HANDLING

Request inspection

Rejects interactive shells and records SSH exec requests without executing the submitted commands.

03 / DEPLOYMENT

Isolated lab

Python prototype with Docker support. Run inside a disposable VM or isolated network, never as a public production service.
